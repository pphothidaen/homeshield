⚙️ EMBEDDED DESIGN PATTERNS 03 / 05

Built for Constrained
Router Hardware

Stock ISP routers have tiny RAM and fragile NAND Flash. Four guardrails keep the network resilient:

01
FNV-1a 64-bit Zero Flash Wear
Computes streaming checksums in volatile RAM (/var/tmpfs). If the blocklist hash matches, NAND Flash is never written.
02
128 KB Streaming Buffer + Flyweight
Reuses String buffers and shares whitelists via Arc, eliminating 600k+ heap allocations and holding memory flat at 408 kB VmRSS.
03
RAM Canary Verification
Every deploy tests the static ARMv7 Rust binary (445 KB) in RAM first. Any ABI anomaly triggers automatic fallback to the POSIX shell engine.
04
4-Tier Fail-Safe Rollback Hierarchy
L1: Atomic Toggle (<100ms via SIGHUP) • L2: Shell Fallback (<5s)
L3: Full Factory Uninstall (<30s) • L4: Smart TV ADB Restore (<10s)
